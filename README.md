# Guide9-CUDA-ASCOM

**[Télécharger le ZIP / Download the ZIP](Guide9-CUDA-ASCOM.zip)**

## Français

Ce pack complète une installation Windows de **Guide 9.1 du 1er janvier 2019**. Il accélère l’indexation des astéroïdes MPCORB avec CUDA, permet le pilotage de la monture via ASCOM et ajoute une passerelle vers l’Assistant de cadrage de N.I.N.A. [Notice française](Lisez-moi.txt)

Ferme Guide et les outils du pack. Sauvegarde les fichiers à remplacer, puis copie le contenu du ZIP dans le dossier qui contient `guide9.exe`. Lance `Guide9-CUDA.exe`.

Pour importer une cible, lance aussi `Guide9-NINA.exe`. Dans les options Planétarium de N.I.N.A., choisis **Cartes du Ciel**, hôte **localhost**, port **3293**. Centre la cible dans Guide puis, dans **N.I.N.A. → Cadrage**, clique sur l’**épingle** à droite de **Coordonnées**.

## English (US)

This Windows package requires the **January 1, 2019 build of Guide 9.1**. It accelerates MPCORB asteroid indexing with CUDA, adds ASCOM mount control, and includes a bridge to the N.I.N.A. Framing Assistant. [English instructions](Readme-EN.txt)

Close Guide and any package tools. Back up the files you will replace, then extract the ZIP alongside `guide9.exe`. Launch `Guide9-CUDA.exe`.

To import a target, also launch `Guide9-NINA.exe`. Set the N.I.N.A. planetarium to **Cartes du Ciel**, host **localhost**, port **3293**. Center the target in Guide, then click the **pin** next to **Coordinates** in the N.I.N.A. Framing Assistant.
